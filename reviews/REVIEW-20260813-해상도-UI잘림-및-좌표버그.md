## 수정하지 않은 항목
- **`Pucro.spec`의 opencv 포함 여부를 실제 빌드로 확인하지 않음.** hiddenimports는 추가했으나 exe 빌드는 사용자 요청 시 수행하는 규칙이라 빌드하지 않았다. → **중점 확인 요청 참고**
- `execute_image_scan`이 매 순회마다 `config.json`을 다시 읽음 — 실행 중 설정 변경을 반영하려는 의도일 수 있어 동작을 바꾸지 않았다.
- 그룹 탭이 `tree`로 체인 탭의 트리를 넘기지만 그룹 항목엔 `item_id`가 없어 선택 표시가 동작하지 않음 — 무해해서 유지.
- `InfoTab`의 색상/폰트 하드코딩 — 테마 전체와 함께 다뤄야 할 별건이라 제외.
- `.gitignore`의 `*.spec` 때문에 `Pucro.spec`이 git에 추적되지 않음. 빌드 지침이 이 파일을 기준으로 삼는데 버전 관리가 안 되는 상태 — 추적 여부는 사용자 판단이 필요해 손대지 않았다.

## 중점 확인 요청
1. **B5의 판정 완화가 과하지 않은지.** 이제 가상 데스크톱 안이면 모두 통과시킨다. 모니터 배치가 직사각형이 아닌 경우(예: 세로 어긋난 배치) 실제로는 어느 모니터에도 속하지 않는 빈 영역이 가상 영역 안에 생길 수 있는데, 이 좌표도 통과한다. 실제 클릭은 pyautogui가 처리하므로 문제없다고 판단했으나 확인 바란다.
2. **B6의 입력 해제 범위.** `release_all_inputs()`를 항목 단위가 아니라 재생 종료 시점에 호출한다. 항목 사이에 키를 누른 채 유지하는 매크로가 정상 동작하도록 한 선택인데, 반대로 중간에 오류가 나면 다음 항목까지 눌린 상태가 이어진다.
3. **B8의 실제 배포 검증.** exe 빌드 후 이미지 인식이 실제로 동작하는지 확인이 필요하다.
4. 스크롤 컨테이너 도입으로 `_get_active_tab_widget()`의 탭 탐색 방식을 바꿨다(`winfo_children()[0]` → 명시적 매핑). F1~F5, F9 단축키가 모든 탭에서 정상인지 확인 바란다.
